# 销售接待流程与话术（演示样例数据）

> 说明：本文件为本地 Demo 演示用样例，车型配置、价格与政策以门店当期正式资料为准；AI 只提供流程与口径参考，不替代销售顾问的正式报价与承诺。

## 接待开场
- 客户到店后先问候、引导入座，了解购车用途：家用通勤、长途出行、网约运营还是家庭第二台车。
- 依次确认关键信息：预算区间、是否有固定车位或家充条件、车牌所在地、是否有旧车置换。
- 记录客户关注点（续航、空间、补能效率、安全、智能化），再据此介绍对应车型，不强行推高配。

## 车型介绍要点
- 续航、动力、空间、配置等参数，以随车手册和官方配置表为准，不夸大、不跨车型套用参数。
- 智能化与驾驶辅助功能，只说明官方公布的适用范围，不承诺脱手自动驾驶或未开放的功能。
- 对比竞品时陈述本车型客观参数，不贬低、不编造对手缺点。

## 试驾安排
- 试驾前确认驾驶证有效、讲解路线与安全注意事项，签署试驾确认。
- 试驾路线尽量覆盖城市道路、减速带与快速路段，让客户体验起步、制动与静谧性。
- 试驾后主动询问感受，记录客户仍在意的点，约定下一步跟进时间。

## 报价与方案呈现
- 车辆成交价、保险、上牌、金融服务费、选装等分项列明，最终落地价以门店盖章报价单为准。
- 金融方案需结合客户征信由金融机构审批，AI 不承诺贷款一定通过或具体利率。
- 优惠、补贴、交付周期等敏感信息，引导到销售顾问出具正式书面方案。

## 接待话术边界
- 不夸大续航与性能，不承诺低于当期政策的折扣，不保证审批结果。
- 资料未覆盖的车型细节、特殊定制、合同条款，转人工顾问处理。
- 客户情绪激动或涉及投诉、合同争议时，先安抚并转交专人，不在话术层面自行答复。
