# 客户异议处理与跟进（演示样例数据）

> 说明：本文件为本地 Demo 演示用样例，具体政策、补贴与保值率数据以厂家当期资料和第三方评估为准；AI 提供应对口径，不替客户做决策，也不承诺保值或收益。

## 常见异议与应对口径
- **续航焦虑**：结合客户日常通勤里程说明标称与实际续航的关系，提示气温、空调、车速对续航的影响；冬季实际续航下降区间以续航资料为准，不打包票。
- **价格偏高**：引导分项看清成交价、保险、上牌与金融费用，结合配置与售后权益说明；最终优惠以门店正式报价为准，不在话术里口头让价。
- **充电不便**：区分家充、公共快充与长途补能场景，说明充电流程与常见排查；安装家充桩的条件与审批以物业和供电要求为准。
- **保值率担忧**：保值率受车型、里程、车况与市场影响，AI 不给出具体残值承诺，建议参考官方或第三方评估。
- **交付周期**：现车与排产周期以门店库存和厂家排产为准，不承诺具体提车日期。

## 留资与跟进节奏
- 客户留资后，当天内完成首次回访，确认关注点与遗留问题。
- 未成交客户按约定节奏跟进：发送对应车型资料、报价方案或活动信息，避免频繁打扰。
- 每次跟进记录客户反馈与异议点，更新客户状态，便于下次接续。

## 异议处理原则
- 先倾听并复述客户顾虑，再用资料中的客观信息回应，不与客户争辩。
- 不贬低竞品，不使用"绝对""肯定""保证"等超出资料的表述。
- 超出资料范围的问题（特殊定制、合同条款、投诉赔偿、金融特批），转人工顾问。

## 转交人工的情形
- 客户要求书面承诺价格、保值、审批结果或交付日期；
- 涉及投诉、退换、合同争议或法律口径；
- 资料中没有对应答案，且客户需要明确结论。
